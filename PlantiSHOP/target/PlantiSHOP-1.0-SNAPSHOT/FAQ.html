Preguntas Frecuentes sobre la Aplicación

¿Qué es PlantiSHOP?

Es una aplicación, tanto web como móvil, dirigida a quienes disfrutan de la jardinería. Ofrece un jardín virtual, un mercado digital, un analista de datos y una inteligencia artificial :3

¿Cómo funciona el Jardín Personal?

Es un repositorio donde los usuarios registran y consultan sus plantaciones físicas, junto con el estado actual de cada una ;3

¿Cómo se Comercializa en PlantiSHOP?
  1. Explora productos disponibles en el mercado :3
  2. Envía solicitudes al vendedor con cantidad, lugar, fecha y hora del encuentro ;3
  3. El vendedor acepta o rechaza la solicitud :3
  4. El cliente confirma o cancela. Si se confirma, ambas partes reciben un archivo con los detalles del acuerdo :3
¿Qué es el Apartado PREMIUM?

Es un área exclusiva para usuarios con suscripción, donde acceden al analista de datos y a la inteligencia artificial ;3

¿Qué es Basil.IA?

Es un chatbot de jardinería disponible para usuarios PREMIUM. Brinda consejos y puede identificar plantas a partir de una imagen JPEG ;3

¿Cómo funciona el Analista Estadístico-Predictivo?

Usa estadística para graficar avances, generar resultados y hacer predicciones del comportamiento del mercado y los usuarios PREMIUM :3
